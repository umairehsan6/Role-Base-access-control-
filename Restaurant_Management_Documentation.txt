------------------------------------------------------------
🎯 Project Overview
------------------------------------------------------------


The Django Restaurant Management System is a comprehensive web application designed to streamline restaurant operations through role-based interfaces for waiters, kitchen staff, and administrators. The system provides real-time order management, inventory tracking, and detailed analytics.

>>> Core Objectives

  • **Efficiency**: Streamline order-to-kitchen workflow
  • **Real-time Communication**: WebSocket-based live updates
  • **Inventory Management**: Automated stock tracking
  • **Analytics**: Data-driven insights for business decisions
  • **Security**: Local deployment with role-based access control

---

------------------------------------------------------------
🚀 Core Features
------------------------------------------------------------


>>> 👨‍🍳 Waiter Interface

  • **Menu Management**: Browse dishes with preparation times and categories
  • **Table Assignment**: Select tables and specify guest count
  • **Order Placement**: Create orders with real-time status tracking
  • **Timer System**: 30-minute auto-reminders for order follow-up
  • **Kitchen Alerts**: Real-time notifications with sound and modal popups
  • **Payment Processing**: Calculate totals, change, and drawer management

>>> 🔪 Kitchen Interface

  • **Order Dashboard**: View all active orders across multiple screens
  • **Audio Notifications**: Sound alerts for new orders
  • **Status Management**: Update orders (Pending → In Progress → Completed)
  • **Collaborative Workflow**: All chefs can view and update any order
  • **Real-time Updates**: Live synchronization across all kitchen devices

>>> 🛠️ Admin Interface

  • **Inventory Management**: Add/edit ingredients and stock levels
  • **Unit Configuration**: Set measurement units (grams, liters, pieces)
  • **Automated Calculations**: Real-time inventory deduction post-order
  • **Sales Analytics**: Comprehensive reporting dashboard
  • **Daily Reports**: Automated earnings summaries
  • **AI Integration**: Weekly OpenAI LLM-powered business insights

>>> 📊 Dashboard / Counter Screen

  • **Order Queue**: Visual status tracking (Pending/In Progress/Completed)
  • **Real-time Monitoring**: Live order updates
  • **Financial Tracking**: End-of-day drawer balance calculations
  • **Performance Charts**: Dish popularity and sales metrics

------------------------------------------------------------
👥 User Roles & Permissions
------------------------------------------------------------


>>> 🔐 Role-Based Access Control (RBAC)


Role            | Permissions     | Access Level   
----------------------------------------
| Waiter | Order management, table assignment, payment processing | Frontend interface, order creation |
| Chef | Order status updates, kitchen notifications | Kitchen interface, order workflow |
| Admin | Full system access, inventory, analytics, user management | All interfaces, system configuration |
| Manager | Order oversight, basic analytics | Waiter + partial admin features |

>>> Authentication Features

  • Secure login system with encrypted passwords
  • Session management with automatic timeout
  • Role-based route protection
  • Multi-device login support

class Order(models.Model):
    ORDER_STATUS = [
        ('pending', 'Pending'),
        ('in_progress', 'In Progress'),
        ('completed', 'Completed'),
        ('cancelled', 'Cancelled'),
    ]
    
    order_number = models.CharField(max_length=20, unique=True)
    table = models.ForeignKey(Table, on_delete=models.CASCADE)
    waiter = models.ForeignKey(CustomUser, on_delete=models.CASCADE)
    guest_count = models.IntegerField()
    status = models.CharField(max_length=20, choices=ORDER_STATUS)
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)
    estimated_completion = models.DateTimeField()
    total_amount = models.DecimalField(max_digits=10, decimal_places=2)
    
class OrderItem(models.Model):

from rest_framework import viewsets, status
from rest_framework.decorators import action
from rest_framework.response import Response
from channels.layers import get_channel_layer
from asgiref.sync import async_to_sync

class OrderViewSet(viewsets.ModelViewSet):
    queryset = Order.objects.all()
    serializer_class = OrderSerializer
    
    def create(self, request):
        serializer = self.get_serializer(data=request.data)
        if serializer.is_valid():
            order = serializer.save(waiter=request.user)
            
            # Update inventory
            self.update_inventory(order)
            
            # Send real-time notification to kitchen
            self.notify_kitchen(order)
            
            return Response(serializer.data, status=status.HTTP_201_CREATED)
        return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)
    
    @action(detail=True, methods=['post'])
    def update_status(self, request, pk=None):
        order = self.get_object()
        new_status = request.data.get('status')
        
        if new_status in ['pending', 'in_progress', 'completed']:
            order.status = new_status
            order.save()
            
            # Notify all relevant parties
            self.broadcast_status_update(order)
            
            return Response({'status': 'updated'})
        return Response({'error': 'Invalid status'}, status=status.HTTP_400_BAD_REQUEST)
    
    def update_inventory(self, order):
        for item in order.items.all():
            dish_ingredients = DishIngredient.objects.filter(dish=item.dish)
            for dish_ingredient in dish_ingredients:
                ingredient = dish_ingredient.ingredient
                required_quantity = dish_ingredient.quantity_required * item.quantity
                ingredient.current_stock -= required_quantity
                ingredient.save()
    
    def notify_kitchen(self, order):
        channel_layer = get_channel_layer()
        async_to_sync(channel_layer.group_send)(
            'kitchen_orders',
            {
                'type': 'new_order',
                'order': OrderSerializer(order).data
            }
        )
    
    def broadcast_status_update(self, order):
        channel_layer = get_channel_layer()
        async_to_sync(channel_layer.group_send)(
            f'order_{order.id}',
            {
                'type': 'status_update',
                'order': OrderSerializer(order).data
            }
        )

import json
from channels.generic.websocket import AsyncWebsocketConsumer
from channels.db import database_sync_to_async
from .models import Order, CustomUser

class OrderConsumer(AsyncWebsocketConsumer):
    async def connect(self):
        self.user = self.scope["user"]
        
        if self.user.role == 'chef':
            self.group_name = 'kitchen_orders'
        elif self.user.role == 'waiter':
            self.group_name = f'waiter_{self.user.id}'
        elif self.user.role == 'admin':
            self.group_name = 'admin_dashboard'
        
        await self.channel_layer.group_add(
            self.group_name,
            self.channel_name
        )
        await self.accept()
    
    async def disconnect(self, close_code):
        await self.channel_layer.group_discard(
            self.group_name,
            self.channel_name
        )
    
    async def receive(self, text_data):
        data = json.loads(text_data)
        message_type = data['type']
        
        if message_type == 'order_status_update':
            await self.handle_status_update(data)
        elif message_type == 'join_order_room':
            await self.join_order_room(data['order_id'])
    
    async def new_order(self, event):
        await self.send(text_data=json.dumps({
            'type': 'new_order',
            'order': event['order'],
            'sound': True,  # Trigger sound notification
            'modal': True   # Show modal popup
        }))
    
    async def status_update(self, event):
        await self.send(text_data=json.dumps({
            'type': 'status_update',
            'order': event['order']
        }))
    
    async def handle_status_update(self, data):
        order_id = data['order_id']
        new_status = data['status']
        
        # Update order status in database
        await self.update_order_status(order_id, new_status)
        
        # Broadcast to all relevant groups
        await self.channel_layer.group_send(
            f'order_{order_id}',
            {
                'type': 'status_update',
                'order_id': order_id,
                'status': new_status,
                'updated_by': self.user.username
            }
        )
    
    @database_sync_to_async
    def update_order_status(self, order_id, status):
        try:
            order = Order.objects.get(id=order_id)
            order.status = status
            order.save()
            return True
        except Order.DoesNotExist:
            return False

class RoleBasedPermission(BasePermission):
    def has_permission(self, request, view):
        if not request.user.is_authenticated:
            return False
        
        # Define role-based access
        role_permissions = {
            'admin': ['GET', 'POST', 'PUT', 'DELETE'],
            'manager': ['GET', 'POST', 'PUT'],
            'waiter': ['GET', 'POST'],
            'chef': ['GET', 'PUT']  # Only status updates
        }
        
        user_role = request.user.role
        allowed_methods = role_permissions.get(user_role, [])
        
        return request.method in allowed_methods

from cryptography.fernet import Fernet

class EncryptedField(models.CharField):
    def __init__(self, *args, kwargs):
        self.cipher = Fernet(settings.ENCRYPTION_KEY)
        super().__init__(*args, kwargs)
    
    def from_db_value(self, value, expression, connection):
        if value is None:
            return value
        return self.cipher.decrypt(value.encode()).decode()
    
    def to_python(self, value):
        if isinstance(value, str):
            return value
        return self.cipher.decrypt(value.encode()).decode()
    
    def get_prep_value(self, value):
        if value is None:
            return value
        return self.cipher.encrypt(value.encode()).decode()

class SecurityHeadersMiddleware:
    def __init__(self, get_response):
        self.get_response = get_response
    
    def __call__(self, request):
        response = self.get_response(request)
        
        # Add security headers
        response['X-Content-Type-Options'] = 'nosniff'
        response['X-Frame-Options'] = 'DENY'
        response['X-XSS-Protection'] = '1; mode=block'

from celery import shared_task
from django.utils import timezone
from .models import DailyReport, Order, Payment

@shared_task
def generate_daily_report():
    today = timezone.now().date()
    
    # Calculate metrics
    orders_today = Order.objects.filter(created_at__date=today)
    total_orders = orders_today.count()
    total_revenue = sum(order.total_amount for order in orders_today)
    total_customers = sum(order.guest_count for order in orders_today)
    
    avg_order_value = total_revenue / total_orders if total_orders > 0 else 0
    
    # Find most popular dish
    from django.db.models import Count
    popular_dish = OrderItem.objects.filter(
        order__created_at__date=today
    ).values('dish').annotate(
        count=Count('dish')
    ).order_by('-count').first()
    
    # Create or update daily report
    report, created = DailyReport.objects.get_or_create(
        date=today,
        defaults={
            'total_orders': total_orders,
            'total_revenue': total_revenue,
            'total_customers': total_customers,
            'average_order_value': avg_order_value,
            'most_popular_dish_id': popular_dish['dish'] if popular_dish else None
        }
    )
    
    return f"Daily report generated for {today}"

class AnalyticsDashboardView(APIView):
    permission_classes = [IsAuthenticated, IsAdminUser]
    
    def get(self, request):
        # Date range parameters
        start_date = request.query_params.get('start_date', timezone.now().date() - timedelta(days=7))
        end_date = request.query_params.get('end_date', timezone.now().date())
        
        # Generate analytics data
        analytics_data = {
            'revenue_trend': self.get_revenue_trend(start_date, end_date),
            'order_status_distribution': self.get_order_status_distribution(start_date, end_date),
            'popular_dishes': self.get_popular_dishes(start_date, end_date),
            'hourly_performance': self.get_hourly_performance(start_date, end_date),
            'table_utilization': self.get_table_utilization(start_date, end_date),
            'payment_methods': self.get_payment_method_distribution(start_date, end_date)
        }
        
        return Response(analytics_data)
    
    def get_revenue_trend(self, start_date, end_date):
        from django.db.models import Sum
        from django.db.models.functions import TruncDate
        
        revenue_data = Order.objects.filter(
            created_at__date__range=[start_date, end_date],
            status='completed'
        ).annotate(
            date=TruncDate('created_at')
        ).values('date').annotate(
            revenue=Sum('total_amount')
        ).order_by('date')
        
        return list(revenue_data)
